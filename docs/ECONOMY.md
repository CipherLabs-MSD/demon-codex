# Economy

PROPOSAL: Gold is normal gameplay currency; Souls is scarcer/premium-like;
Essence is a crafting resource with possible elemental variants.
No exchange rates, drop probabilities, prices, supply caps or balances are approved.

| Candidate sources | Candidate sinks |
| --- | --- |
| Gameplay, quests, events, rewards, purchases | Forge, upgrades, crafting, cosmetics, events, Altar/Sacrifice |

PROPOSAL: duplicates + essence + resources → upgraded/special collectible.
Common → Uncommon → Rare → Epic → Legendary → Infernal is a conceptual Forge path,
not a promise of linear conversion. Later recipes may require specific demons,
sigils, relics and event resources. Hidden recipe predicates remain restricted.

## Assumptions versus decisions

Assumption: making duplicates useful improves collection satisfaction; validate
with playtests. Assumption: an Altar could provide optional resource sinks; its
purpose and loss protections are UNKNOWN.
WORKING DECISION: no numerical economy balancing during foundation. Future material
parameter changes require human review, simulation evidence and rollback planning.
CANON: XP, levels, Gold, Souls, Essence, Energy, quests, ordinary inventory,
abilities, matchmaking and combat results stay normal game/backend data.
