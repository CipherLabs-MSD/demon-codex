# Codex

CANON: canonical demon slots span 001–666. Do not create a 667th canonical slot.
PROPOSAL: completion UI displays discovered entries and unknown placeholders;
discovery belongs to the player/account, not the shared demon definition.
Pages may show portrait, released lore, rarity variants, editions, skins, relics
and authorized provenance. Ownership and discovery are separate concepts.

PROPOSAL: anomalous entities use an independent namespace with no canonical number.
UNKNOWN, UNNUMBERED, FORBIDDEN, LOST and ASCENDED are provisional display concepts,
not finalized labels. Do not infer additional public content from restricted plans.
See the [schema proposal](../../content/README.md) for identity separation.
