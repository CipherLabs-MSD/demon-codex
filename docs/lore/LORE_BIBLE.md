# Lore bible

CANON: the universe contains 666 canonical demons and a mysterious master smith
known by the working title The Black Forgemaster. Demonic essence can be forged.

PROPOSAL: specialized historical Forged roles include Wardens, Hunters, Heralds
and Executioners. These do not define finalized characters, factions or mechanics.

RESTRICTED: additional narrative material exists; this repository contains no full
secret identities or discovery requirements. Writers work from approved briefs.
All new names, histories and relationships start as PROPOSAL until human approval.
See [Forgemaster](FORGEMASTER.md), [Codex](CODEX.md), [Mythics](MYTHICS.md).
